# ADS-1-.Semestre
Sistema de Gestão de Pesquisas de Satisfação 📊Este repositório contém o desenvolvimento completo de um Sistema Web para Gestão de Pesquisas e Questionários, focado em garantir o anonimato dos usuários e a eficiência na coleta de dados institucionais. O projeto integra as disciplinas de Engenharia de Software I, Algoritmos e Projeto Integrador I.  📝 Sobre o ProjetoO sistema permite que instituições criem questionários personalizados para diferentes categorias de participantes (Alunos, Professores e Colaboradores). A aplicação utiliza um método de senhas anônimas e únicas, garantindo que as respostas não sejam vinculadas à identidade do usuário, mas permitindo a segmentação estatística.  🚀 Funcionalidades PrincipaisO sistema é dividido em módulos operacionais:  Módulo de Pesquisa: Cadastro, edição e controle de períodos (data de início e fim) das pesquisas.  Módulo de Questionários: Criação de perguntas dinâmicas (múltipla escolha, booleana, escala e texto) associadas a categorias específicas.  Módulo de Senhas: Geração de lotes de senhas aleatórias e únicas, com exportação para PDF ou CSV.  Módulo de Dashboard: Acompanhamento em tempo real do total de respostas, senhas geradas e taxa de participação.  Módulo de Relatórios: Geração de análises estatísticas e comparativos entre categorias com visualização gráfica.  🛠️ Tecnologias UtilizadasCom base no levantamento tecnológico realizado para o projeto:  Front-endHTML5 / CSS3: Estruturação semântica e estilização responsiva.  JavaScript / TypeScript: Interatividade e tipagem estática para maior segurança.  Bootstrap / React: Frameworks para interface e componentes reutilizáveis.  Back-end & Banco de DadosNode.js / PHP (Laravel) / Java (Spring Boot): Opções de stack para processamento de APIs REST.  MySQL / PostgreSQL: Armazenamento relacional das pesquisas e respostas.  SegurançaCriptografia de senhas no banco de dados.  Conformidade com a LGPD (Lei Geral de Proteção de Dados) para anonimato total.  🔐 Algoritmo de Geração de SenhasComo parte da curricularização de extensão, foi desenvolvido um algoritmo específico para o controle de acesso:  Regra de Negócio: As senhas possuem 8 caracteres, sendo o primeiro caractere o identificador da categoria (P - Professor, A - Aluno, F - Funcionário).  Implementação: O algoritmo valida a categoria, gera caracteres aleatórios (A-Z, 0-9, @!#) e armazena os resultados em vetores.  Exemplo: Uma senha de professor poderia ser PDITROE#.  👥 AutoresNeandro Bueno Vieira   Elvys Monteiro Filho   Vitor Hugo Dias Mantovani   Matheus Cardoso de Oliveira Bispo   Lucas Augusto Vieira Tridapali   Wagner Alves de Souza   Este projeto foi desenvolvido como parte integrante do 1º Semestre de 2026 do curso de ADS na FATEC Lins.
